About
-------------------------------------------------
TestQuiz is an app designed for teachers and students, in which the teachers make their tests and send them to students, and students complete them. This repository contains the telegram bot side of the project, meant for both sides.

Features
----------------------------------------------------------------
 - Ability to make classes with users, which have started the bot
 - Ability to import tests made by the desktop app
 - Ability to see your tests and classes
 - Ability to send tests to people in classes
 - Teacher callback: sending the amount of questions answered correctly by each student and their answers
 - Ability to create tests right in the bot

Future plans
--------------------------------------------------

 - Add images to questions
 - New kinds of questions
 - Quality Of Life changes
